# Book_Recommendation_System
A content-based/collaborative filtering Book Recommendation System developed using Python, Flask, Pandas, NumPy, and Machine Learning. The system recommends books similar to a selected book based on user-book rating patterns and displays popular books with their ratings, authors, and cover images.  
## Dataset

This project uses the Book-Crossing Dataset.

The dataset contains information about:
- Books
- Users
- Book ratings

The original dataset can be downloaded from Kaggle:

https://www.kaggle.com/datasets/arashnic/book-recommendation-dataset

### Dataset Files

- Books.csv
- Ratings.csv
- Users.csv

The raw dataset files are not included in this repository because of their large size.
